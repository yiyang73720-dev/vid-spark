# Larry Williams COT 指数回测（2006–2026）

这是一个可以完整重跑的研究回测：用 Larry Williams 的方法，看 CFTC 持仓报告（COT）里
“商业持仓者”的 COT 指数，能不能预测之后的价格。主要看**原油**，同时检验**黄金、白银、大豆、糖**，
时间范围 **2006-06 到 2026-09**。

结论先说：**没有发现可靠的优势。** 预先指定的主结果（原油）甚至比随便买入还差一点。

## 方法（白话版）

1. **数据**：CFTC **Disaggregated（分类）报告，期货 + 期权合并（F+O）**，每周一份。
2. **商业持仓者**（Larry 说的“内部人 / 聪明钱”）= 生产商/贸易商（Producer/Merchant）+ 掉期交易商（Swap Dealers）。
   `净持仓 comm_net = (两者多头之和) − (两者空头之和)`
3. **COT 指数**（回看 N 周，包含本周）：
   `指数 = 100 × (本周净持仓 − 过去 N 周最低) / (过去 N 周最高 − 过去 N 周最低)`
   N = 26（主）、52、156。
4. **信号**：指数 ≥ 80 → 做多信号；指数 ≤ 20 → 做空信号（80/20 为主，另测 75/25、90/10）。
   连续几周都有同一信号算一“段”（episode）。
5. **入场时间（不偷看未来）**：报告的持仓日期一般是周二，CFTC 在周五下午才发布。
   所以用**发布之后的那个周二**（遇假日顺延到下一个交易日）的收盘价入场，不用周五收盘价。
6. **政府停摆**：2013-10、2018-12-18 至 2019-02-26、2025-09-30 至 2026-01-20 期间报告延迟发布，
   这些周的信号**不计入**（当时实际拿不到数据）；但它们仍参与计算指数的最高/最低值。
7. **远期收益**：入场后第 5×h 个交易日的收盘价，h = 1、4、8、13 周。
   **基准** = 同一市场所有可用周的平均收益；**超额** = 信号周平均收益 − 基准。
8. **置换检验（循环平移）**：把信号序列整体循环平移一个随机步数（26 到 T−26），重复 2000 次，
   看“随机时点”的平均收益有多少次不低于真实信号。
   `p = (1 + 次数) / (1 + 2000)`。循环平移保留了信号扎堆和收益自相关，比普通打乱更公平。
9. **事先指定的主结果**（看结果之前就定好）：**原油，N=26，80/20，持有 8 周**。

全部网格：5 个市场 × 3 个 N × 3 组阈值 × 多/空 × 4 个持有期 = **360 个组合**。
详细定义见 [SPEC.md](SPEC.md)。

## 主要结果

**原油，N=26，80/20，做多，持有 8 周**（`work/engine/canonical.csv`）：

| 指标 | 信号周 | 基准（全部周） |
|---|---|---|
| 样本 | 273 个信号周 / 51 段 | — |
| 平均收益 | **−1.38%** | +1.83% |
| 超额 | **−3.21%** | — |
| 胜率 | 52.4% | 56.0% |
| 置换检验 p | **0.96** | — |

- **全部 360 个组合**：只有 **8 个 p < 0.05，而且全是白银做空**（纯随机时预期约 18 个）；
  经 Benjamini–Hochberg 多重检验校正（q = 0.10）后 **0 个显著**。
- **最新一期报告 2026-09-29**：原油 26 周指数 = **63.57**，不在 80/20 区间，**没有信号**。

## 局限

- 用的是 **Disaggregated F+O**（期货 + 期权合并），**不是** Larry 原来用的 **Legacy 纯期货**报告；
  “生产商/贸易商 + 掉期交易商”只是对 Legacy“商业持仓”的近似。
- 分类报告从 2006 年才开始，所以只有 **2006 年以后**的数据。
- 原油价格是 **CL 连续合约**（未复权），换月时有价格跳空；2020-04-20 的负价被剔除。
- **2026-10-06 和 2026-10-13 两期报告缺失**：抓数据时 cftc.gov 无法访问。原油期货价格只到 2026-10-05。
- COT 和价格数据来自第三方 GitHub 仓库；因为访问不了 cftc.gov，没有与官方原始文件逐一核对。
- **本项目仅供研究，不构成任何投资建议。**

## 如何运行

需要：bash、git、Python ≥ 3.11，能访问 github.com 和 raw.githubusercontent.com。

```bash
pip install -r requirements.txt
./run_all.sh                 # 下载数据 → 引擎 → 各项检验（lens）→ 报告数据，约 2–3 分钟（不含下载）
./run_all.sh --skip-fetch    # 数据已下载过，跳过下载
./run_all.sh --crosscheck    # 另外跑两个独立实现（implA/implB）并与引擎逐项核对
LARRY_COT_ROOT=/某个目录 ./run_all.sh   # 数据和输出放到别的目录
```

所有路径都从一个根目录 `ROOT` 算起：环境变量 `LARRY_COT_ROOT`，不设就用本目录。

```
ROOT/ext/    下载的第三方仓库（固定 commit）      ROOT/data/   整理后的 CSV
ROOT/work/   全部输出（engine/、lens_*/、implA/、implB/、report/data.json、logs/）
```

`data/`、`ext/`、`work/` 都在 `.gitignore` 里：**不提交任何数据和结果**（第三方价格数据的授权不明确）。

| 目录 | 内容 |
