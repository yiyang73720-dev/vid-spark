# USD News · Forex Factory — TradingView 美元新闻时段指标

把 Forex Factory 日历里所有 **USD** 相关新闻标到 TradingView 图表上，告诉你**什么时候出什么新闻**，并把新闻前后的「不交易时段」标出来，方便盘中避开。

| 文件 | 作用 |
|---|---|
| `USD_News_ForexFactory.pine` | TradingView 指标（Pine Script v6） |
| `ff_usd_news.py` | 下载 Forex Factory 数据并写进指标（可选，只用 Python 标准库） |
| `test_ff_usd_news.py` | `ff_usd_news.py` 的测试 |

## 图表上会看到什么

- **右上角新闻列表**：接下来的 USD 新闻，包括时间、影响级别、事件名、预测值、前值和倒计时。第一行会直接告诉你现在能不能交易：
  - `⛔ 新闻窗口中，暂停交易 · 至 20:45（还剩 12分）`
  - `⚠️ 8分后进入新闻窗口（20:15–20:45）`
  - `✅ 可交易 · 下个窗口 周五 10-02 20:15（2小时15分后）`
- **竖线 + 标签**：每个发布时间一条竖线，标签写着时间和事件名（红 = 高影响，橙 = 中，黄 = 低）。同一时间有多条新闻时合并成一个标签（`+3` 表示还有 3 条），鼠标悬停可以看到全部的预测值和前值。
- **背景色**：新闻前后的屏蔽窗口（默认高影响前后 15 分钟，中影响前后 5 分钟，非农 / CPI / FOMC / 利率决议 / 美联储主席讲话前后 30 分钟）。
- **虚线**：还没走到的未来窗口，用两条虚线标出起止时间。

## 使用步骤

### 1. 添加指标

TradingView → 底部 **Pine 编辑器** → 新建 → 删掉默认代码 → 粘贴 `USD_News_ForexFactory.pine` 的全部内容 → **保存** → **添加到图表**。

### 2. 放入本周数据（二选一，每周做一次）

Pine Script 不能联网，所以数据需要你每周送进去一次。

**方法 A：直接粘贴（不需要安装任何东西）**

1. 用浏览器打开 <https://nfs.faireconomy.media/ff_calendar_thisweek.json>（Forex Factory 官方的本周日历导出）。
2. `Ctrl+A` 全选、`Ctrl+C` 复制（Firefox 请先点「原始数据 / Raw Data」）。
3. 图表上指标的 ⚙️ 设置 → **Forex Factory JSON（整页粘贴）** → 粘贴 → 确定。

整页包含所有货币，指标会自动只留 USD。注意这种方式只对当前这一个图表上的指标生效。

**方法 B：用脚本写进代码（多个图表一起更新，还能保留前几周的历史）**

```bash
cd tradingview/usd-news
python3 ff_usd_news.py
```

脚本会下载本周数据，在终端列出 USD 事件，并把数据写进 `USD_News_ForexFactory.pine`。然后在 Pine 编辑器里用新文件的全部内容替换旧代码并保存，所有用这个指标的图表都会更新。

常用参数：

| 参数 | 说明 |
|---|---|
| `--tz Asia/Shanghai` | 终端里用什么时区列时间（默认本机时区） |
| `--next-week` | 同时尝试下载下周数据（Forex Factory 不一定提供） |
| `--file week.json` | 脚本下载被拦时，用浏览器另存的 JSON（或 XML）文件 |
| `--print-json` | 输出只含 USD 的精简 JSON，可以粘贴到方法 A 的输入框（比整页小很多） |
| `--currency USD,CNY` | 换成 / 增加其他货币 |
| `--keep-days 14` | 保留多少天以前的历史事件 |

脚本会把数据缓存在同目录的 `.ff_cache.json`，每周累积，所以回看上周的 K 线也能看到当时的新闻。5 分钟内重复运行会直接用缓存，避免被 Forex Factory 限流（`--force` 可以强制重新下载）。

> Forex Factory 的「本周」是纽约时间的周日到周六。建议周日或周一开盘前更新一次；周中如果 Forex Factory 临时加了讲话之类的事件，再更新一次即可。

### 3. 设置提醒（可选）

图表上方 ⏰ **创建警报** → 条件选 **USD News** → **任何 alert() 函数调用**。之后会收到：

- 新闻发布前 N 分钟的提醒（默认 15 分钟，默认只提醒高影响），内容里有事件名、预测值和前值；
- 新闻窗口开始 / 结束的提醒。

如果只想要「窗口开始 / 结束」这种简单提醒，也可以在条件里选 `USD 新闻窗口开始` 或 `USD 新闻窗口结束`。

## 设置说明

| 分组 | 设置 | 默认 |
|---|---|---|
| 数据 | **货币** | `USD`（可以写 `USD,CNY`，或 `ALL`） |
| 数据 | **显示时区**：请和图表右下角的时区一致 | `Asia/Shanghai` |
| 数据 | **自定义事件**：每行一条，例如 `2026-10-02 20:30 H 非农`（时间按显示时区；级别 H/M/L 或 高/中/低 或 假日；只写日期 = 全天） | 空 |
| 新闻屏蔽窗口 | 高 / 中 / 低影响：是否显示，以及前 / 后多少分钟 | 高 15/15，中 5/5，低不显示 |
| 新闻屏蔽窗口 | ⭐ 重大事件关键词，以及它们的前 / 后分钟数 | `Non-Farm\|CPI\|FOMC\|Federal Funds Rate\|Fed Chair`，30/30 |
| 图表显示 | 背景色、竖线、未来窗口虚线、标签（简洁 / 详细 / 关闭）、显示过去几天 | 全开，7 天 |
| 图表显示 | **事件名称语言**：English / 中文 / 中文 + English | English |
| 新闻列表 | 位置、条数、字号、是否显示预测值 / 前值 | 右上，8 条 |
| 提醒 | 提前几分钟、最低提醒级别、窗口开始 / 结束提醒 | 15 分钟，高 |

## 在自己的策略 / 指标里使用

指标输出两个隐藏序列（只在数据窗口里显示）：

- `USD news window (1 = inside)`：当前 K 线在新闻窗口内为 1，否则为 0；
- `Minutes to next USD news`：距离下一条新闻还有多少分钟。

在你自己的脚本里用 `input.source()`，选择 `USD News: USD news window (1 = inside)`，就能实现「新闻窗口内不开仓」。

## 常见问题

- **为什么不能自动更新？** TradingView 的 Pine Script 不能访问外部网站，所以只能粘贴或者用脚本写进代码。
- **倒计时不动？** 倒计时在每次有新报价时刷新，休市时会停在打开图表的那一刻。
- **为什么没有「实际值」？** Forex Factory 的周导出里只有预测值和前值。
- **全天 / 待定的事件**（例如银行假日）只出现在列表里，不画竖线，也不设屏蔽窗口。
- **时间对不上？** 检查「显示时区」是否和图表右下角的时区一致。数据本身带时区偏移，所以夏令时切换不会出错。
- **粘贴后没反应？** 确认复制的是整段 JSON（以 `[` 开头、`]` 结尾）。如果输入框装不下，改用 `python3 ff_usd_news.py --print-json` 输出的精简版，或者用方法 B。
